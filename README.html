Subnet Calculator

Python mein banaya gaya ek tool jo IP address aur subnet mask se network details calculate karta hai. CLI aur GUI (Tkinter) dono versions available hain.

Subnetting kya hai?

Subnetting ek bade network ko chhote-chhote parts (subnets) mein baantne ka tarika hai. Companies isko use karti hain:

  • Security ke liye — alag department (HR, Finance, IT) alag subnet mein, taaki ek jagah problem aaye to doosri jagah asar na ho
  • Traffic manage karne ke liye — poora network ek jagah slow nahi hota
  • IP address bachane ke liye — jitne devices utna hi size ka subnet banate hain, waste nahi hota
  • Troubleshooting aasan — problem sirf ek subnet mein dhundhni padti hai, poore network mein nahi

Network Engineers aur System Admins ye kaam roz karte hain jab naya office ya server setup karte hain.

Calculation kaise hoti hai (concept)

Example: IP = 192.168.1.10, Mask = 255.255.255.0 (/24)

  1. Network Address = IP aur Mask ka AND (jahan mask 255 hai wahan IP ka number, jahan 0 hai wahan 0): 
    192.168.1.10  AND  255.255.255.0  =  192.168.1.0
  2. Broadcast Address = Network ke host-part ko 255 (sab 1) bana do: 
    192.168.1.255
  3. Usable Range = Network se ek aage, Broadcast se ek pehle: 
    192.168.1.1  se  192.168.1.254
  4. Total Hosts = last octet mein 0-255 = 256
    Usable Hosts = 256 − 2 = 254

CIDR number (/24) batata hai ki mask mein kitne bits 1 (network) hain — jitna chhota CIDR utna bada subnet, jitna bada CIDR utna chhota subnet.

Kaise chalayein

CLI version:

python3 subnet_calculator.py

IP aur CIDR/mask terminal mein type karo, Enter dabao — result print ho jayega.

GUI version:

python3 subnet_calculator_gui.py

Ek window khulegi, IP aur CIDR box mein daal kar "Calculate" button dabao.

Files

  • subnet_calculator.py — Terminal-based version
  • subnet_calculator_gui.py — Tkinter GUI version

Requirements

Python 3.x (GUI ke liye Tkinter, jo Python ke saath hi aata hai)
